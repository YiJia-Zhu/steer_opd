# Steering能否改善OPD适配：两个方向方案与SFT冷启动

更新：2026-11-11。**当前尚无正式跨family训练收益结论。**
论文设置见[证据表](02_paper_settings.md)，公式和实现细节见[执行说明](03_execution_plan.md)。

最新用户决定：先验证Rethinking共享词表配对，对照Base→OPD与Base+steer→OPD，
画accuracy与overlap曲线。本地SFT组及下载暂缓，论文结果仅作背景，不能由此
得出steer相对SFT的同条件结论。这一验证先于下文C1；用户已选择
OpenThoughts3中的100题做OPD，AIME2025仅评测。建议先重复100题做50个训练步，
**主方案在整个OPD训练阶段的loss前向中，对所有参与loss的回答token预测状态
注入方向，rollout及评测关闭steer。** 此前“只用前10步”降为后续日程消融。
下面的方案1和方案2都保留，两者区别在方向构造，共用这套训练流程。
已讨论的两组先导面板先比较普通OPD和方案1；是否同时纳入方案2另行冻结，
不能把“总方案有两个方向”误写成方案2已进入已批准的运行队列。当前未启动GPU或下载。
主动简化验证不构成跨family无效的结论，也不自动恢复其他实验队列。

## 1. 我们想解决什么

**能否用少量教师文本提取学生空间方向，在OPD训练中帮助学生利用教师监督，
承担一部分师生模式适配作用，从而减少或省去独立的冷启动SFT？**

教师自己做题很强，不代表它对学生推理过程给出的指导就容易被学生学会。
我们尝试从少量教师示范中提取学生自己的激活方向，看看能否改善这一步。

主评测在训练完成后关闭steer，检验收益是否进入学生参数。“测试时不注入”与
“训练中途提前撤去”分开；本方案不要求先在第10步撤去。

总体问题覆盖跨family适配，当前先用Rethinking共享词表配对验证基本机制，再
依据证据决定是否进入跨family。效果与结论限于实际测试范围。“同一教师、多个
学生”是后续可选对照，不是首轮要求。

## 2. 方案1：比较教师回答和学生自己的回答

1. 先取128道独立校准题，让教师和初始学生分别给出推理回答。
2. 冻结学生，让它分别读取这两类文本，提取同一层的内容激活。
3. 每题先平均，再跨题平均，得到方向：
   `v = 学生读教师回答的激活 - 学生读自身回答的激活`。
4. 学生照常生成训练轨迹；整个OPD阶段的loss前向，在所有有效回答预测状态
   加入固定方向，更新学生参数。
5. 每次评测和最终部署都关闭方向。只在前H步启用属于后续消融。

**两项激活都由同一个学生计算。** 教师文本和学生自身文本通常各做一次prefill，
共两次。先只用一个中间层、一个全局方向，与同层同强度的随机、负方向比较。

## 3. 方案2：比较大教师和小参考模型的回答

借鉴Compass：尝试提取大教师相对同家族小参考模型的差异，看看它是否比方案1的
总差方向更有用。

以计划中的C1配对为例，对**同一道题**收集三份文本：

| 文本 | 谁生成 |
|---|---|
| 大教师的推理回答 | Qwen3-30B-A3B-Instruct-2507 |
| 小参考模型的推理回答 | 同家族的Qwen3-0.6B |
| 学生自己的推理回答 | 还没进行本轮训练的Granite4.1-3B学生 |

然后，**三份文本都让同一个冻结学生读取**。下面的“激活”全部来自这个学生：

| 用途 | 方向 |
|---|---|
| 方案1 | 读大教师回答的激活 − 读学生自身回答的激活 |
| 方案2 | 读大教师回答的激活 − 读小参考回答的激活 |
| 额外对照 | 读小参考回答的激活 − 读学生自身回答的激活 |

**方案2本身只需要前两类文本。** 第三类是为了与方案1和额外对照一起比较而保留的。
单独提取方案2通常需要两次学生prefill；一起比较三个方向时，共读取三类文本。

想检验的是：大、小教师之间的差异，是否比大教师与学生之间的总差异，更适合
帮助学生学习。目前不能认定它就是“纯能力方向”。

方案2可以接普通OPD，也可以接Compass。比较时保持相同训练目标，先看换方向
是否有用，再看与Compass组合是否有额外收益。小参考的文本生成和学生读取计入
成本；只有使用Compass目标时，才额外需要它对训练轨迹做概率评分。

单独方案2用T/R两份文本即可；一起比较时用同一三文本池化协议和样本权重，
才能比较`v_total_triplet = v_cap + v_offset`。不能把按不同协议提取的方案1向量
直接带入并声称严格分解成立。

## 4. 两个方案怎样注入，以及与SFT冷启动的关系

**两种方向方案当前共用“全有效回答预测位置注入”的固定基线。** 这是一种需要
验证的覆盖策略，不代表每个位置都需要或都受益于steer。同一层的
全局方向按位置复用，训练前提取后固定；不需要每个token重新提取或调用教师生成。
每个token依然有其对应的教师概率监督及学生梯度，方向不代替OPD目标。
这里“每个token”描述注入覆盖范围；训练时可按batch中的位置mask一次性加向量，
不要求为每个token分别做一次模型前向。

若回答token位于输入位置t，注入的是预测它的状态t−1；首个回答预测状态在
prompt末位。除此之外不额外覆盖prompt编码位置，padding及无效位置排除。
回答原生终止token是否计入按原版loss mask一致处理。hook保持到backward重算
结束；普通rollout、教师/参考评分、无干预诊断、评测与部署均关闭学生hook。

两条训练路径是：

| 路径 | 学生怎样获得适配 |
|---|---|
| SFT冷启动→OPD | 先用教师完整回答做独立SFT更新，再进行普通OPD |
| Base→steer辅助OPD | 直接从Base开始OPD，在训练前向用固定方向辅助参数学习 |

第二条路径尝试承担第一条路径中一部分模式适配作用。**能否减少或替代独立SFT，
以及总成本是否更低，是实验问题。** SFT也可能传递方向无法概括的内容；方向提取
仍需文本生成和学生读取，OPD仍需教师概率评分，成本均需记录。

SV Training §4.1/4.3提供训练期方向注入、测试关闭的参考；把它迁移到OPD是本
项目待验证设计。该文§5.1 GRPO用正确−错误方向修正advantage，是另一种机制。
Rethinking模板对齐从输入侧改善相容性，也应与方向效应分开控制。

本轮暂缓SFT对照，仅能比较steer是否优于匹配的普通OPD；如果要主张它替代SFT，
后续仍需同条件SFT→OPD及成本对照。原论文SFT曲线作为背景，不能代替本地对照。

### 4.1 是否根据熵差或overlap选择注入位置

方向方案1/2回答“用什么向量”；固定或动态门控回答“在哪些位置、用多大强度”。
这两个设计轴独立，任何一种方向都可配任一种门控。统一写成
`h_tilde[t-1] = h[t-1] + alpha * g[t] * v`。

- 固定基线：全部有效回答位置`g[t]=1`。
- 待验证的overlap门控：先在同一普通学生前缀上计算无hook的
  `O[t]=|Top16(S) intersect Top16(T)|/16`，例如取`g[t]=1[O[t]<tau]`。
  门控只决定是否加方向，OPD监督仍保留全部原有效位置，不能顺便改成筛token loss。
- 熵差先作辅助诊断。`H_S-H_T`描述置信程度的差异，无法单独判断候选是否一致；
  两个模型可以熵相同而候选完全不同，也可以候选相近而置信程度不同。

低overlap也不自动表示该位置值得steer。Rethinking §5.2有overlap更低、共享
概率质量更高且效果更好的设置。应同时记录共享质量及无hook学习收益，不能仅
追求更高overlap，也不能只在低overlap位置加方向后就认为已定位瓶颈。

门控必须由本次更新前、未加steer的学生/教师分布计算，固定并停止梯度，覆盖
本次loss前向和backward重算；不使用steer后的指标反过来决定同一次注入。
若OPD已缓存所需top-K可复用，否则额外统计或学生前向须计成本。完整词表熵与
top-K条件熵分开命名；异构分词器需另定义共同事件及熵尺度。

建议先验证固定全位置steer是否有用，再比较overlap门控；熵差组合后置。
门控对照至少包括同样注入比例、同层、同方向和同强度的随机位置mask，排除仅因
少加方向而受益。阈值或注入比例用训练/独立dev预先确定，不依据AIME测试曲线选。
跳过向量加法未必减少模型前向成本；记录评分、额外前向和总耗时。
动态门控目前仅为候选设计，未实现、未批准加入首轮运行。

## 5. 师生分词不一样怎么办

参考Compass，按共同文本边界对应。例如学生把`unbelievable`看成1个token，
教师拆成3个，就在完整文本片段上对应；对应不上的位置跳过并报告比例。
Compass对多token片段取平均token log-prob作评分，这不等于整个单词的概率。

分词对齐负责把监督接上，steering负责检验学生能否更好地学会这些监督。
训练中普通生成与带方向前向的分布差异，也需要正确处理：方法消融先使用明确的
候选分布loss，原版Compass基线另列。具体公式和适用范围见执行说明技术附录。

## 6. 怎样判断有效，与谁比较

主要看：**关闭方向评测的学生是否学得更好，或用更少总成本达到相近成绩。**
主方案的训练阶段持续使用方向；提前撤去的价值另做日程消融。

| 对照 | 要回答的问题 |
|---|---|
| 普通OPD | 加方向是否有额外收益？ |
| 同范数随机方向、负方向 | 收益是否来自这个方向，而非一般扰动？ |
| 同一批教师回答做full SFT→OPD | 普通SFT是否已足够？ |
| 同一批回答做LoRA→OPD | 更轻量的Simple式warm-up是否已足够？ |
| SV-SFT→OPD | 参考论文的训练方法是否已能达到同样效果？ |
| Compass及其方向组合 | 改监督信号是否已足够，方向是否还能提供帮助？ |

每组从相同学生起点出发，给SFT/LoRA合理调参机会。按Compass共同SFT起点比较时，
所有组使用同一个SFT checkpoint。成本包括示范生成、学生读取、搜索及训练。

Overlap只作诊断；它升高不等于学生真正学会。最终以关掉方向后的学习收益为准。

## 7. 效果不好时怎么回退

先排查分词、实现、长度和训练预算，再用dev决定路线：

| 结果 | 下一步与结论范围 |
|---|---|
| 跨family有稳定收益 | 确认种子与成本，再考虑其他师生或等规模控制；结论限于已测试配对 |
| 跨family无收益，共享词表设置有效 | 回到Rethinking口径，研究共享词表下的训练辅助或冷启动成本，不再声称解决跨family |
| 两边都无收益 | 保留负结果，停止扩大方法与搜索 |

回退要重新做对应实验，跨family负结果保留。路线选择不用MATH-500；单纯复现
已有“SFT有效”的结果，也不作为新方法贡献。

## 9. 数据和实验规模

- 正式设计先128道独立校准题；本轮100题先导暂按已讨论方案复用训练题校准。
  方案1收集教师和学生回答，方案2需要教师/小参考回答；完整比较共享三份文本。
- 保留完整、非退化文本，记录正确率和截断。各方法共享题目和相应教师示范。
- 正式设计将训练与校准/dev分开，dev-select选配置，dev-confirm确认冻结选择。
  本轮复用训练题只作小规模验证，固定候选层/强度，不依据AIME测试曲线调参。
- MATH-500始终保留为测试，不用于选模型、方向或决定是否回退。

先做短程学习和必要对照，有希望再延长到50/100步。确认实际收益后，才进入长
训练、多种子、方案2与Compass组合或更多学生。两个方向方案均保留；一起检验时
主面板应有普通OPD、方案1、方案2三组。10步没有差异不足以证明无效，搜索预算也
不无限扩大。具体检查和待办见[执行说明](03_execution_plan.md)及[AGENTS](../AGENTS.md)。
