# 基于教师同家族差分与动态激活干预的 OPD 研究方案

> 本方案是一份可用于讨论和启动实验的研究设计。文献结论、方法假设和待验证结果在文中分别表述；所有预期效果均不代表已有实验结果。

## 1 先明确我们要做什么

我们研究这样一个问题：**当强教师与学生的推理分布不相容时，能否在学生内部提取一个体现教师能力增量的激活方向，并在教师与学生高概率候选明显不一致的位置按需注入，从而改善 on-policy distillation 的学习效果？**

默认主方案是：

1. 选择强教师 $T$、与强教师同家族的小参考模型 $R$，以及待训练学生 $S_\theta$。
2. 用一小批训练题，让三个模型分别生成回答；随后由**同一个冻结初始学生 $S_0$** 读取这些回答。
3. 主方向取“学生读大教师回答的激活”减去“学生读教师同家族小参考回答的激活”。
4. 在 OPD 的学生生成过程中，比较教师与学生在**相同学生前缀**上的预测分布；仅根据 overlap 决定当前预测是否注入该方向。
5. 学生在受控生成策略下接受原有教师的 OPD 监督，教师参数和蒸馏目标的基本形式保持固定。
6. 最终主指标是**去掉 steering 后，学生独立推理的准确率**。训练时的即时对齐效果作为机制证据单独报告。

另外两种向量差、每个 token 都注入、只在后段注入，都必须保留为实验对照。向量统一在训练开始前提取一次并冻结，不把“何时提取”和“是否逐题动态提取”扩展成独立研究轴。

题目可暂定为：**面向分布不相容师生的动态激活干预蒸馏**。在没有跨家族实验结果之前，标题和摘要不直接宣称“解决跨家族 OPD”。

## 2 故事逻辑

### 2.1 我们真正要解决的问题

OPD 的优势是让学生先生成自己的推理轨迹，再由教师对这些学生实际访问的状态提供逐 token 监督。它减少了“训练时只见教师轨迹、测试时却沿学生轨迹生成”的偏差。

但“监督来自强教师”并不等于“监督对当前学生有效”。学生可能采用与教师不同的推理组织方式、表达习惯和局部续写偏好。此时，教师虽然独立解题能力很强，却未必能在学生已经走到的前缀上提供学生容易吸收的指导。跨家族是这一问题的一个重要场景，同家族但初始 overlap 较低的师生也可能出现类似困难。

因此，我们关注的是**教师能力与学生可学习性之间的缺口**：教师有额外能力，学生却不能通过普通 OPD 充分获得这些能力。我们不把所有分布差异都视为坏事，因为教师的新能力本身就可能表现为与学生不同的预测。

### 2.2 目前方法怎么处理

已有方法大致从三处入手。

**第一类先改学生初始化。** Rethinking OPD 和 Simple-OPD 使用教师生成的推理过程进行 SFT cold start／warm-up，让学生先熟悉教师的推理模式，再进行 OPD。这说明推理兼容性可以改善，但也带来一个问题：是否必须通过一轮对教师轨迹的参数拟合，才能得到这种兼容性？

**第二类改蒸馏信号。** CompassOPD 认为，强外部教师与学生之间的似然差，混合了教师家族与学生之间已有的偏移，以及同一教师家族从弱到强带来的增量。它借助教师同家族的小参考模型，分离后一个信号，再用冻结学生参考约束更新。

**第三类改教师或训练时的激活。** SPTA 先适配教师，使其更能在学生前缀上续写；ACSD 和 ST-OPSD 对自蒸馏教师施加 activation steering；Steering Vectors as a Training Signal 已经研究了在 SFT 和教师强制蒸馏过程中向学生隐状态注入方向。因此，“steering 可以帮助蒸馏”本身不能作为本工作的主要新意。

### 2.3 我们的方法是什么

我们的切入点是：**不先把教师的整个行为分布搬进学生，而是尝试在学生内部表示教师相对同家族小参考的差异，再在需要时用这一方向辅助 OPD。**

这里有两个递进的设计。

第一，选择“教什么”的表示。直接比较教师回答和学生回答，容易把能力、家族习惯、格式和长度都混在一起。主方案改为比较强教师与其同家族小参考的回答，再由学生读取二者，得到学生空间内的差分方向。这样有望减少教师家族共有成分的影响，突出强教师相对小参考的变化。

第二，选择“在哪里干预”。全程注入可能扰动已经相容的预测，也可能在教师自身不可靠的位置施加不必要的偏置。主方案仅利用当前前缀上的 overlap，在师生高概率候选分歧较大时进行干预。熵差门控作为独立对照，不与 overlap 叠加。

这两点都属于待验证假设。尤其是，CompassOPD 在同一前缀、同一文本动作上的似然分解，并不能直接证明“不同回答的平均激活差”能够消除家族偏移。我们的实验需要验证这种迁移是否成立。

### 2.4 一段可以直接用于组会的表述

> 强教师未必是当前学生容易学习的教师。已有研究表明，OPD 的有效性与师生在学生访问状态上的推理兼容性有关；跨家族蒸馏还会把家族偏移与教师能力增量混在一起。现有方法主要通过 SFT 预热学生、重构似然监督，或适配教师解决问题。我们尝试从学生表示侧提供另一条路径：让同一个初始学生读取强教师与教师同家族小参考的回答，提取二者的激活差作为候选能力方向，再根据当前前缀上的师生 overlap 动态决定是否干预学生。我们希望用少量、按需的表示干预改善 OPD 的可学习性，并通过去掉 steering 后的学生表现，检验收益是否真正进入参数。

## 3 研究问题与可证伪假设

| 研究问题 | 核心假设 | 什么结果会削弱或否定它 |
| --- | --- | --- |
| 哪种向量差更适合 OPD | 大教师减教师同家族小参考，比大教师减自身更能保留有益增量 | 主方向不如另外两种方向，或不优于等范数随机方向 |
| 是否需要每个 token 都注入 | 根据 overlap 触发，比熵差单指标门控及同等注入预算的随机或固定位置触发更有效 | 动态门控的收益可被相同注入率的随机门控解释 |
| steering 改善了什么 | 不仅改变当下输出，还改善后续 OPD 学习 | 只有测试时继续加 steering 才提升，裸学生不提升 |
| 跨家族是不是关键边界 | 分布不相容比家族标签更能解释收益 | 效果只随某个模型或格式变化，不能在低 overlap 设置复现 |
| 少量方向是否足够 | 单层固定方向能成为有用的训练辅助 | 只有逐题答案向量、大量额外生成或复杂控制器才有效 |

**不提出“overlap 越高，最终准确率必然越高”的假设。** overlap 是局部兼容性的代理指标，可能受常见词、格式和概率排序影响；教师也可能自信地给出错误续写。真正的成功标准仍是最终任务表现和训练收益。

## 4 相关工作的准确定位

### 4.1 Rethinking OPD 提供问题动机

Rethinking On-Policy Distillation of Large Language Models 研究了推理模式相容、新知识和 OPD 成功之间的关系。其部分实验中，师生共享的 top-k token 集合承载约 97%–99% 的概率质量，限制到 overlap token 的优化也能获得有效收益。[1]

这里应区分“共享集合承载大量概率质量”“限制监督到共享集合仍然有效”和“所有场景下共享集合必然贡献固定比例的梯度”。本方案使用前两项作为经验动机，不把第三项当成普遍定理。该论文关于跨家族的讨论，也不能代替我们自己的跨家族验证。

### 4.2 CompassOPD 提供差分动机

在同一前缀 $c$、同一对齐文本动作 $z$ 上，CompassOPD 的分解可写为：

$$
\ell_T(z\mid c)-\ell_{S_\theta}(z\mid c)
=\underbrace{\ell_R(z\mid c)-\ell_{S_\theta}(z\mid c)}_{\text{参考模型与学生的偏移}}
+\underbrace{\ell_T(z\mid c)-\ell_R(z\mid c)}_{\text{教师同家族增量}}.
$$

其最终更新信号还包含学生相对冻结初始参考的锚定项。该工作在跨家族设置上已有直接实验。[2]

本方案借鉴的是“先用教师同家族参考作差”的思路，但实施位置不同：CompassOPD 在输出似然空间分离信号；我们在学生读取回答后的激活空间构造方向。由于 $y^T$ 和 $y^R$ 通常不是同一轨迹，后者没有前者同样的消偏保证。

### 4.3 直接 steering 训练已经有前作

Steering Vectors as a Training Signal in LLM Post-Training 已经使用“初始学生读参考回答”减去“初始学生读自身回答”的方向，在教师强制监督训练及蒸馏中进行隐状态干预；其全局方向也可以在训练前提取并冻结。[3]

所以，本工作中的“大教师减自身”必须是有分量的直接对照。我们相对它的主要增量应落在：**教师同家族参考差分、学生自身 rollout 上的 OPD，以及由当前师生分歧决定的干预策略**。不能把“激活向量参与参数训练”写成首次提出。

### 4.4 与 ACSD 和 ST-OPSD 的区别

ACSD 从同一基座模型的不同轨迹中提取方向，将其持续注入冻结自教师，由学生学习该教师在学生前缀上的分布。[4] ST-OPSD 则在参考条件自蒸馏中，干预教师以抑制引用不存在的参考、恢复重新检查行为。[5]

我们的默认方案干预的是**学生**，教师仍是独立强教师。方向来自强教师与教师同家族小参考的文本对照。共同点是将激活干预用于训练，但指导来源、干预对象和要解决的具体失配不同。

### 4.5 与其他适配方法的区别

Simple-OPD 支持“教师兼容的 CoT warm-up 有助于 OPD”，并显示在其设置中，错误教师轨迹也可能带来相近的预热收益。[6] 这提醒我们，方向收益可能主要来自推理组织方式，而未必来自正确性；因此实验应包含格式、长度和正确性控制。

SPTA 修改教师参数以适应学生前缀。[7] 我们先保持教师固定，以区分“让教师更会教”和“让学生当前状态更容易学”两种作用。

BSD 使用外部教师文本作为特权上下文，通过学生同构的自教师提供学生词表内的监督。[8] 它是跨 tokenizer／纯文本教师场景的重要参考，但与本方案直接比较外部教师分布的 OPD 路线不同。若改用 BSD 式桥接，应作为单独变体，不能混入主方法后仍宣称监督完全相同。

## 5 问题定义与默认实验边界

### 5.1 模型角色

| 符号 | 角色 | 在主方案中是否训练 |
| --- | --- | --- |
| $T$ | 独立强教师，提供回答和 OPD 监督 | 否 |
| $R$ | 强教师同家族的小参考模型 | 否 |
| $S_0$ | 训练前的学生，负责离线读取三类回答 | 否，可离线完成后释放 |
| $S_\theta$ | 实际参与 OPD 的学生 | 是 |

**小参考优先来自大教师的家族，而不是学生家族。** 它与大教师应尽量匹配模型代际、指令／思考模式和后训练路线，同时具有明确能力差距。只匹配参数量不足以排除这些混杂。小参考与学生规模接近有助于解释，但不作为硬条件。

所有激活差都由 $S_0$ 计算。我们不相减教师隐向量和学生隐向量，也不需要跨模型隐藏维度映射。

### 5.2 数据划分

使用四份功能不同的数据：

- $D_{\mathrm{vec}}$：构造方向的小规模训练子集。
- $D_{\mathrm{opd}}$：OPD 的训练题。
- $D_{\mathrm{dev}}$：选择层、强度、门控阈值和训练配置。
- $D_{\mathrm{test}}$：最终评价，任何阶段都不用于提取方向、阈值校准或选 checkpoint。

第一版让 $D_{\mathrm{vec}}$ 与 $D_{\mathrm{opd}}$ 题目不重合，便于判断全局方向是否可迁移；二者都来自允许使用的训练数据。SFT warm-up 基线必须能够使用同一批教师回答。不能让本方法多见教师数据，却只与完全没有这些数据的普通 OPD 比较后声称更省样本。

初始建议用 256–512 道题构造方向，规模仅作工程起点，不是预先确定的最优值。使用可自动校验最终答案的数学任务，先避免把验证器误差和代码方向迁移问题混入主线。

### 5.3 词表边界先说清楚

**学生内部提取方向可以跨 tokenizer；直接计算师生 top-k overlap 和全词表 KL 则不可以。**

第一版机制实验优先选共享 tokenizer、token ID 语义和词表支持都兼容的师生对，以便严格计算同一前缀上的完整分布。初始低 overlap 同家族配对是允许的机制验证设置。

跨家族实验优先寻找实际兼容的 tokenizer 配对；必须检查词表、特殊 token、聊天模板和文本边界，不能仅凭模型名称认定兼容。若使用不同 tokenizer，按第 11 节单独处理，不把文本 span 的似然对齐误当成完整下一 token 分布对齐。

## 6 方向提取 重点比较三种向量差

### 6.1 生成同题回答并由同一个学生读取

对 $x_i\in D_{\mathrm{vec}}$，分别得到：

$$
y_i^T\sim T(\cdot\mid x_i),\qquad
y_i^R\sim R(\cdot\mid x_i),\qquad
y_i^S\sim S_0(\cdot\mid x_i).
$$

随后用 $S_0$ 的 tokenizer 和聊天模板，将同一个题目与三种回答分别编码，进行不注入 steering 的因果 teacher-forcing 前向。不能把三种模型自己的隐藏状态拿来相减。

设 $h_{0,\ell,t}(x,y)$ 是 $S_0$ 在第 $\ell$ 层、回答位置 $t$ 的 residual-stream 表示，定义：

$$
\phi_\ell(x,y)=\frac{1}{|M(x,y)|}
\sum_{t\in M(x,y)}h_{0,\ell,t}(x,y).
$$

$M$ 只包含回答正文 token，排除题干、padding、角色标记等模板成分；是否保留推理分隔符应统一。先对每道题的回答取平均，再对题目取平均，避免长回答在全数据集中获得更大的样本权重。

三种回答长度通常不同，**不做不同轨迹之间的逐 token 位置相减**。平均池化避免了强行对齐，但不自动消除长度、风格和内容混杂，后面仍需控制实验。

### 6.2 方案一 大教师回答减学生自身回答

$$
d_\ell^{T-S}=\frac1N\sum_{i=1}^N
\left[\phi_\ell(x_i,y_i^T)-\phi_\ell(x_i,y_i^S)\right].
$$

它刻画学生读取教师回答与自身回答时的总体表示差异。优点是直接、无需小参考模型，也有前作基础；风险是把能力、家族风格、答案正确性和推理长度等混合在一起。该方案既可能有效，也可能因包含大量无关偏移而不如主方案。

它是最重要的方向基线，不能只给很弱的默认设置。三种方向使用相同提取题、池化、层选择和强度搜索预算。

### 6.3 方案二 大教师回答减教师同家族小参考回答

$$
\boxed{
d_\ell^{T-R}=\frac1N\sum_{i=1}^N
\left[\phi_\ell(x_i,y_i^T)-\phi_\ell(x_i,y_i^R)\right]
}
$$

这是主方案。它试图利用强弱模型共享家族背景的条件，减弱家族共有成分，保留强教师相对小参考的变化。因为读取者仍是学生，最终方向天然处于学生的表示空间。

需要谨慎命名：实验前称它为**教师同家族差分方向**，或“候选能力方向”。不能提前把它称为纯能力向量。大小模型可能还有思考模式、训练数据和输出长度差异；不同语义轨迹的池化差也未必与局部 next-token 更新方向一致。

只有在该方向相对其他方向和混杂控制持续有效时，才更有依据将其解释为有利于能力迁移的差分。

### 6.4 额外对照 小参考回答减学生自身回答

$$
d_\ell^{R-S}=\frac1N\sum_{i=1}^N
\left[\phi_\ell(x_i,y_i^R)-\phi_\ell(x_i,y_i^S)\right].
$$

这组非常关键。它帮助判断收益是否主要来自“让学生接近教师家族的表达／推理习惯”，而不是强教师相对小参考的增量。

如果 $d^{R-S}$ 比 $d^{T-R}$ 更好，合理结论是当前学生更需要家族适配，而不是继续坚持方案二。若 $d^{T-S}$ 最好，则说明对该设置而言，整体差异比拆开的增量更有用。

### 6.5 利用三者的代数关系做诊断

在相同题目、相同过滤集合、相同池化和相同样本权重下，未经归一化的方向满足：

$$
d_\ell^{T-S}=d_\ell^{T-R}+d_\ell^{R-S}.
$$

因此可以报告三者的范数、余弦相似度，以及 $T-R$ 与 $R-S$ 是否相互抵消。这为“为什么方案一不如方案二”提供可检查的表示层证据。逐个单位归一化后的向量不再满足该等式，不能混用。

若设置正确教师回答过滤，必须先选定一份共同题目集合，再对三种方向一起计算；各自筛出不同题目后就不能再利用上述精确分解。

### 6.6 归一化与注入位置

统一使用：

$$
v_\ell=\frac{d_\ell}{\|d_\ell\|_2+\epsilon},\qquad
\widetilde h_{\ell,t}=h_{\ell,t}
+\alpha\,g_t\,s_\ell v_\ell.
$$

$s_\ell$ 是从训练校准数据估计的该层 residual 向量典型 L2 范数，提取后固定；$\alpha$ 表示相对激活尺度的干预强度。随机方向、反向方向以及三种差分均采用相同尺度协议。若 $\|d_\ell\|$ 接近零，先检查信噪比，不通过除以极小范数强行放大噪声。

第一版只使用一个学生层，在 block 输出、进入下一 block 之前注入。候选层取约 $0.4L,0.5L,0.6L$，经验证集选择一个。提取和注入使用完全相同的 hook 定义。不同学生允许选择不同层，因为已有工作显示层配置不一定跨骨干直接迁移。[3]

强度初始可试 $\alpha\in\{0.01,0.03,0.1\}$，并始终保留 $\alpha=0$ 基线。数值只是统一尺度后的起始搜索，不代表已有最优配置。

### 6.7 不扩展方向提取时机

所有主实验都在 OPD 开始前，用 $S_0$ 一次性提取全局方向，训练中冻结。没有每道题读取其教师答案后再生成，没有训练中周期刷新，也没有测试时读取目标答案。

这既控制成本，也让实验聚焦于“减谁”和“何时注入”。已有全局固定方向的前作可作为选择依据，[3][4] 没有必要再把提取时机变成第三条主线。

## 7 动态门控 什么时候给学生注入

### 7.1 只使用一个主门控信号

**主方法只使用 overlap，不与熵差做 AND／OR 组合。** 每个预测步只需要计算一个相容性指标，再与一个阈值比较。熵差保留为独立门控对照和机制诊断指标。

在生成第 $t$ 个回答 token 前，当前状态是：

$$
c_t=(x,y_{<t}).
$$

教师在这一学生前缀上的分布记为 $q_t=T(\cdot\mid c_t)$。学生先执行一次当前步不注入的探测前向，得到 $p_t^{\mathrm{probe}}$。这里的“不注入”只指**当前步**，历史状态可能已经受此前 steering 影响。

不能把学生沿自身前缀的分布，与教师沿教师自己回答前缀的分布直接比较。那会把“前缀不同”和“模型不同”混在一起。

对兼容词表，定义：

$$
O_t=\frac{|\operatorname{TopK}(p_t^{\mathrm{probe}})
\cap\operatorname{TopK}(q_t)|}{k}.
$$

初始固定 $k=16$，与 Rethinking OPD 的一项主要设置衔接。[1] 指标从 softmax 原始分布计算，避免先做 top-p 截断再把采样器变化解释成模型相容性变化。

### 7.2 为什么优先选 overlap

我们的故事是“师生推理分布不相容，使教师能力难以被学生吸收”，overlap 直接度量双方高概率候选是否一致，与这一问题更贴近。

熵或熵差衡量的是不确定性。两个模型完全可以同样自信，却偏向不同 token；此时熵差可能很小，overlap 仍然很低。如果要求“低 overlap 且学生熵高于教师”，就会额外排除这类自信分歧的位置，而这一排除是否合理本身还需要证明。

因此，第一版先验证“按分歧位置进行干预是否有效”，不把“教师必须相对更确定”作为额外前提。这样既减少一个门控阈值，也能更清楚地判断 overlap 本身有没有价值。

低 overlap 并不保证教师正确，也不保证当前状态可以修复；它还可能反映学生暂时学不会的新能力。这是该单指标规则需要通过实验检验的边界，不在第一版通过叠加条件回避。

### 7.3 默认主门控

$$
\boxed{g_t=\mathbf 1[O_t<\tau_O]}
$$

含义很直接：**overlap 低于阈值就注入，否则不注入。** 触发后使用同一个固定强度 $\alpha$：

$$
\widetilde h_{\ell,t}=h_{\ell,t}+\alpha\,g_t\,s_\ell v_\ell.
$$

方向、层、强度的定义见第 6 节；门控本身只有一个阈值 $\tau_O$。门控和指标都停止梯度；学生不能通过对门控函数反向传播来投机性改变触发。

在训练校准前缀上，以约 10%–30% 的初始触发率构造阈值候选，再由验证表现确定一个阈值。该范围只是校准起点，不是训练中必须维持的注入配额。主实验固定阈值，报告触发率如何随训练自然变化；不使用测试集设阈值。

第一版不使用联合门控、不让强度随 overlap 连续变化，也不加入可学习控制器。先检验最简单的单指标规则。

### 7.4 三种必做注入策略

| 策略 | 定义 | 要回答的问题 |
| --- | --- | --- |
| 每个 token 注入 | 每个回答预测步 $g_t=1$ | 全程干预是否已经足够 |
| overlap 单指标动态注入 | $g_t=\mathbf1[O_t<\tau_O]$ | 按师生分歧干预是否更有效 |
| 只在后段注入 | 达到预设位置后 $g_t=1$ | 作用是否主要来自后段纠偏 |

“每个 step”在这里特指自回归生成的 token 步，而不是只在某个优化器更新步开启。默认只干预回答预测，不对题干 prefill 的所有位置注入；第一个回答 token 的预测边界可以被干预。

后段策略必须有因果定义：不能先知道本次回答最终长度，再回头决定哪些位置属于后半段。可以在独立校准集上估计无干预回答长度中位数 $\widehat L$，预先固定从 $t>0.5\widehat L$ 开始；另报告固定 token 阈值的敏感性。按完成轨迹的 $t/|y|$ 分桶可以用于分析，但不能用于声称在线执行的门控。

### 7.5 熵差作为独立门控对照

熵差对照与 overlap 主方案是二选一地运行，不同时使用：

$$
H(p)=-\sum_{a\in V}p(a)\log p(a),\qquad
\Delta H_t=H(p_t^{\mathrm{probe}})-H(q_t),
$$

$$
g_t^{\mathrm{entropy}}=\mathbf1[\Delta H_t>\tau_H],
\qquad \tau_H\ge0.
$$

该对照只检验“学生比教师更不确定时注入”是否有效，不再要求 overlap 低。这里使用有符号熵差，与 Rethinking OPD 用于监测的绝对熵差 $|H(p)-H(q)|$ 不同。二者可同时记录，但不能混淆。

比较两种单指标门控时，使用相同方向、层、强度和训练预算，并尽量匹配初始注入率；报告训练中实际注入率的变化。若熵差门控稳定更好，就依据结果更换主方案，而不是再叠加两个条件。

再做两个必要对照：

- 等注入率随机门控：随机抽取相同比例的位置；强度一致，检查动态方法是否只是“少加一点”更好。
- 位置匹配随机门控：尽量匹配动态门控的绝对位置分布与注入次数，检查是否只是利用了前／后段的位置规律。

若严格匹配每条完整轨迹的注入次数会用到未来信息，应将其限制为固定前缀离线诊断。在线训练采用仅基于已发生历史的滚动匹配，报告实际匹配误差。

### 7.6 低 overlap 不意味着应该无限加强

极低 overlap 的前缀可能已经严重偏离教师可恢复的状态。此时强行推学生更接近教师也可能有害。第一版仍使用固定强度与单一上阈值，通过 overlap 分桶和教师续写实验判断收益区间。

若干预只在中等失配区间有效，再将其作为适用边界报告；需要时单独研究区间门控，不在第一版默认添加第二个阈值。长轨迹后段也可能同时存在“学生更需要帮助”和“教师更难可靠指导”两种趋势，所以后段注入并不天然优于前段或动态注入。

## 8 OPD 训练闭环

### 8.1 主方案同时在生成与学习前向中使用干预

设受控学生策略为 $\pi_\theta^g$。在给定前缀时，它先计算门控，再按门控注入，最后得到实际采样分布 $p_{\theta,t}^g$。主方案从这个策略生成 rollout：

$$
y\sim\pi_{\theta_{\mathrm{old}}}^g(\cdot\mid x).
$$

本轮数据生成后，在记录的学生前缀和门控上，使用条件反向 KL 的 OPD 更新：

$$
\mathcal L_{\mathrm{OPD}}(\theta)=
\mathbb E_{x,\;y\sim\pi_{\theta_{\mathrm{old}}}^g}
\left[\frac1{|y|}\sum_t
D_{\mathrm{KL}}\left(p_{\theta,t}^g\;\|\;q_t\right)\right].
$$

这是在当前行为策略访问状态上进行的逐状态蒸馏 surrogate；不声称它包含状态访问分布对参数的完整导数。rollout、门控决定、教师目标都停止梯度，学生学习前向保留梯度。每批开始时学习策略与生成策略一致；第一版采用尽量新鲜的 rollout 和较少内循环更新，控制策略陈旧。

**主实现先用兼容词表上的全词表反向 KL。** 如果为了显存使用 top-k 或采样 token 近似，需要明确支持集、重归一化和近似误差，并对所有方法统一。不同 OPD 目标之间的差异不能和 steering 的差异混在一起。

第一版为保持策略定义清楚，rollout 使用温度 1、不做 top-k／top-p 截断的完整采样分布；教师目标同样使用温度 1。若复现框架采用其他温度或截断，须记录实际行为分布，并在所有方法中统一，不能把采样后的行为概率与原始 softmax 概率混为一谈。

### 8.2 门控决定注入 不决定是否蒸馏

当 $g_t=0$ 时，学生在该步不注入，但仍接受正常教师监督。当 $g_t=1$ 时，学生在该步注入，然后接受同一个教师的监督。

因此，主方法没有把训练信号限制在被门控选中的 token，也没有让教师跟着学生的方向一起变化。它改变的是学生的受控表示和由此产生的访问状态，而不是直接裁掉教师监督。

### 8.3 为什么不能含糊地说所有变体都是严格 on-policy

如果只在 rollout 时注入，而更新时直接对不注入的学生计算损失，那么 rollout 来源是 $\pi^g$，学习策略却是 $\pi$。这种设计可以做，但不能把二者当成同一策略。

反过来，只在学习前向注入、rollout 不注入，也会产生行为策略与学习策略的差异。它更接近“在既有学生前缀上施加训练干预”，可能有效，但需单独定义。

主方案选择“生成与更新两侧保持相同干预定义”，先避免这一混淆。只有需要分辨探索效应和梯度效应时，再在小规模实验中比较上述变体；如果涉及较大的行为策略偏移，要明确校正或近似，不能直接套普通 on-policy 的表述。

### 8.4 裸学生收益是成功条件

训练时的受控策略 $\pi_\theta^g$ 与最终无干预学生 $\pi_\theta$ 不是同一个条件策略。训练中增加固定方向，不能自动保证参数会在撤掉方向后保留收益。

因此，所有主结果用**无教师、无参考模型、无 steering、无在线门控**的学生评测。另做带干预评测，只用于区分即时控制效果和参数学习效果，不混入主结果。

若只观察到带干预策略提升而裸学生没有提升，结论应是“干预改善了受控策略，尚未改善独立学生”。可以预先规定一个后续修复实验：将最后约 10% 的训练预算改为无干预普通 OPD，以帮助撤去辅助。该阶段必须计入总预算，并对相应基线采用相同预算和阶段安排；它不是提取时机的新研究轴。

只有通过这一步后的裸学生结果，才能讨论训练收益是否保留。若修复后仍没有保留，就应否定当前训练方案，而不是继续用在线 steering 的成绩替代蒸馏成绩。

### 8.5 完整算法

```text
输入：冻结强教师 T、教师同家族小参考 R、初始学生 S0
      方向集 D_vec、OPD 训练集 D_opd、独立验证集 D_dev

离线阶段
  1. 在相同 D_vec 题目上生成教师、参考和初始学生回答。
  2. 用 S0 读取三类回答，提取同一层的回答正文平均激活。
  3. 分别计算 d(T-R)、d(T-S)、d(R-S)，冻结方向和尺度。
  4. 在训练校准数据和 D_dev 上确定层、强度与门控阈值。

训练阶段
  初始化 Sθ ← S0；如属于 warm-up 轨道，则从同一预热学生开始。
  对每批题目：
    对每道题逐步生成回答：
      a. 取当前已生成学生前缀 c_t。
      b. 教师在 c_t 上给出 q_t。
      c. 学生在历史已确定的受控缓存上，执行当前步不注入的探测前向。
      d. 仅计算 overlap，以 O_t < τ_O 得到停止梯度的 g_t。
      e. 若 g_t=1，在相同当前步状态上注入固定方向并重算输出。
      f. 从实际受控策略采样 y_t；保存 g_t、行为概率及必要元数据。
    用记录的门控重放学生前向，按相同受控策略定义计算 OPD 损失。
    冻结教师与方向，只更新学生参数；及时刷新 rollout。

评测阶段
  去掉方向和门控，仅用学生回答测试题。
  报告准确率、推理长度、生成预算与训练总成本。
```

### 8.6 实现中必须对齐的细节

**门控计算必须早于当前 token 的采样。** 不能读取当前 token 的正确答案、未来 token、完整 rollout 长度或当前题的教师参考回答后再触发。

**预测步与 token 位置有一位偏移。** 预测 $y_t$ 的 logits 来自前缀末位置。首个回答 token 来自 prompt 边界位置，后续预测来自前一个回答 token 位置。hook mask 和损失 shift 必须按预测步对应，不能意外给 $y_t$ 的真实输入状态泄漏未来决策。

**探测缓存和正式缓存要分开。** 当前步先探测再注入时，不能让探测产生的上层 KV 条目混入正式受控前向；重算应从当前步开始前的同一缓存快照出发，最后只提交正式结果。否则实际采样分布与记录的分布不一致。

**训练重放必须复现历史干预。** 不能只在每个位置把向量加上，却忽略上层注意力已经受到前面干预的影响。建议先做逐步生成与带已知 mask 的 teacher-forcing 重放一致性检查，再开展大规模训练。

## 9 实验设计

### 9.1 先选能暴露问题的配对

在独立训练校准题上，使用固定初始学生 rollout，测量各候选教师的初始 overlap、熵差、教师独立解题能力和学生前缀续写能力。基于这些训练侧测量预先选定配对，不根据测试集提升挑配对。

建议至少覆盖：

| 设置 | 选择标准 | 作用 |
| --- | --- | --- |
| 同家族 较高 overlap | 教师有明确能力优势，初始分布较相容 | 检查方法是否只在失配时需要 |
| 同家族 较低 overlap | 教师更强，但初始学生状态上的相容性较差 | 最清楚的机制验证与允许的收敛场景 |
| 跨家族 | 教师明显更强，且词表比较／评分路径可复现 | 验证是否真正改善跨家族迁移 |

每个教师 $T$ 配一个其同家族参考 $R$。不能把一个已经经过教师蒸馏的衍生模型随意标成“独立跨家族”，应披露架构来源、tokenizer 来源和后训练来源。

在可比设置中扩展到至少两种学生骨干或两个学生规模，避免把单一模型的适配现象写成通用结论。模型型号以权重和评分接口实际可得为准，不预设某一配对一定低 overlap 或一定蒸馏失败。

### 9.2 必做三乘三实验矩阵

在一个预先选定的代表性低 overlap 配对上，完成以下矩阵，而不只测试我们偏向的组合：

| 方向 | 每个 token 注入 | overlap 单指标动态注入 | 只在后段注入 |
| --- | --- | --- | --- |
| 大教师减学生自身 $T-S$ | 必做 | 必做 | 必做 |
| 大教师减同家族小参考 $T-R$ | 必做 | **主方案** | 必做 |
| 小参考减学生自身 $R-S$ | 必做 | 必做 | 必做 |

另加不注入的普通 OPD。这样可以分别回答“方向重要吗”“时机重要吗”“二者是否有交互”，而不是两个自由度一起改后无法解释收益。

所有格子使用相同方向构造数据、训练题、OPD 损失、最大长度、学生更新预算和基本调参预算。验证阶段允许各方向用相同大小的强度搜索，不能只精调主方案。

任务数据可先使用一个数学训练集的固定子集启动，选定后冻结采样和去重规则；外部评测至少覆盖 MATH-500 与 AIME 等难度不同的数学集，按题目去除训练重合。最大回答长度从 4K–8K token 起步，由训练侧长度分布和截断比例校准后固定。学习率、批量和更新步数首先沿用能稳定复现普通 OPD 的配置，各方法保持一致；这些工程参数应由首轮校准确定，不凭方法设想预设最优值。

### 9.3 对比方法

| 方法 | 为什么要比 | 比较要求 |
| --- | --- | --- |
| 初始学生 | 提供原始能力起点 | 无额外训练 |
| 普通 OPD | 测量 steering 的增量 | 相同初始化、数据与 OPD 目标 |
| 同数据 SFT warm-up + OPD | 回答为什么不直接预热 | 使用同一批教师回答；报告预热与 OPD 总成本 |
| 教师减自身的全程 steering + OPD | 对应已有 steering 训练思想的直接 OPD 适配 | 不把教师强制蒸馏原论文数值当成同设置结果 |
| CompassOPD | 最接近的教师家族差分方法 | 同教师、同参考、同初始化，保留学生锚定项 |
| 熵感知 OPD | 区分不确定性信号和激活干预的价值 | 按其定义修改 KL 目标，单独标明目标不同 |
| 等注入率随机／位置门控 | 验证动态触发的实际价值 | 同方向、同强度，并报告注入率 |

ACSD、ST-OPSD 与 BSD 用于相关工作定位。若要在同一外部教师条件下实测其变体，需要明确改造后的监督来源和额外信息，不把它们原来的自蒸馏结果直接放入可比主表。SPTA 如有适配后的同教师 checkpoint，可补充比较，但不要求先引入一整套教师 RL 才能开始验证本 idea。

Entropy-Aware OPD 已经根据教师熵调整反向／正向 KL 的组合。[9] 因此，“在 OPD 中利用熵”也不是独立创新；我们的区别是用师生状态差异控制学生激活干预，并保持默认蒸馏目标一致。

### 9.4 初始化要分成两条公平轨道

**无预热轨道：** 普通 OPD 和本方法都从同一个 $S_0$ 开始；另外训练一个使用相同教师文本的 warm-up + OPD 基线，比较各自总预算。这条轨道回答“能否作为 SFT warm-up 的替代或补充”。

**共同预热轨道：** 先得到同一个 warm-up 学生，再比较普通 OPD、CompassOPD 和本方法。此时，方向由该轨道训练开始前的共同学生提取，所有方法共享初始化。它回答“已经有 warm-up 时，方法还有没有增量”。

CompassOPD 原文主实验从共同教师轨迹 SFT checkpoint 开始。[2] 若只在我们的无预热设置中复现它，应标为初始化改变的复现，不能用其退化来证明原方法无效。

### 9.5 必做方向控制

使用相同层、相同尺度、相同门控和相同训练预算，比较：

1. 正向 $+v^{T-R}$、反向 $-v^{T-R}$ 和等范数随机方向。随机方向应抽取多次，避免用一次偶然差结果作证。
2. $T-S$、$T-R$、$R-S$ 三种方向及其原始范数、夹角。
3. 控制输出模板与长度后的方向，检查主结果能否保留。
4. 在同一批“教师和小参考都答对”的题目上重算三种方向，与原始共同题目集合比较，区分正确性差异和解法／表达差异。
5. 在任务相近但题目不重合的方向集上提取，验证全局方向是否只记住个别题目。

这些控制不需要全部与三乘三矩阵交叉。先固定主门控，在代表性配对上逐项验证即可。

注意一个容易做错的负对照：**对于全局均值差，单纯打乱题目配对不是有效方向破坏。** 只要两边样本集合和权重不变，$\frac1N\sum_i a_i-\frac1N\sum_i b_{\pi(i)}$ 与原方向完全相同。应使用随机方向、反向方向或明确改变对照集合的实验，不能声称“乱序后仍有效证明不依赖配对”。

### 9.6 不只看 overlap 提升

主要结果使用裸学生的 benchmark 准确率／pass@1，报告均值、标准差和多次训练随机种子。关键组合建议至少 3 个训练种子；小样本竞赛数学集增加固定数量的评测采样，并给出题目级配对置信区间。选型只使用验证集，测试集在配置固定后运行。

同时报告：

- 裸学生与教师在固定前缀上的 overlap、概率质量 overlap、熵差及 KL。
- 回答长度、截断比例、重复率和有效答案率，防止准确率收益来自放宽生成预算。
- 不同训练步的准确率与总计算量曲线，区分收敛更快和最终更好。
- 动态触发比例、注入位置分布、每题注入次数和门控随训练的变化。
- 总训练时间、教师调用量／评分 token 数、学生额外前向、显存峰值，以及离线构造方向的成本。

Top-k 集合 overlap 之外，可增加概率质量相交系数：

$$
O_t^{\mathrm{mass}}=\sum_{a\in V}\min(p_t(a),q_t(a)).
$$

它不依赖 top-k 的边界排序，但也不能替代任务指标。

## 10 机制证据应该怎样组织

### 10.1 把即时干预和训练后改变分开

对同一批固定学生前缀，测三种状态：

1. 初始学生，不注入。
2. 同一 checkpoint、同一前缀，当前步注入。
3. 完成训练后的学生，不注入。

第二项说明方向能否即时改变当前分布；第三项才说明参数学习的效果。它们必须分别呈现，不能用第二项的 overlap 上升解释第三项尚未出现的准确率收益。

### 10.2 固定前缀诊断和自由 rollout 都要有

自由 rollout 中，方法可能因为访问了更容易的状态而显示更高 overlap。为避免把状态分布变化误解为同状态对齐，固定一组初始学生前缀，对不同方法的 checkpoint 在相同前缀上测量。

固定前缀可以来自 $S_0$，也可以补充多方法前缀混合集合；集合在测量前固定。自由 rollout 则用于观察真实策略轨迹和最终解题表现。两者共同支持结论。

### 10.3 按 overlap 分桶并诊断教师可靠性

主分析只按注入前 overlap 分桶，报告每桶样本量、触发率、即时分布变化和后续续写正确率。熵差仅作为附加诊断指标，需要时再与 overlap 交叉分桶，不进入主门控。尤其检查：

- overlap 较低的区域，是否确实比高 overlap 区域更容易获得干预收益。
- 学生低熵但与教师明显分歧的区域，overlap 门控与熵差单指标门控的表现是否不同。
- 教师高熵或长前缀区域，干预是否带来更多失败。

为了估计教师在某类前缀上的实际指导能力，可对少量固定前缀让教师与学生分别续写，并用最终答案验证。该验证仅用于分析，不作为训练时需要知道最终正确性的门控输入。

### 10.4 长推理分析

按固定绝对位置区间，以及完成后可观察的相对位置，分析触发率、overlap、熵差和续写表现。若动态门控主要发生在后段，还要与位置匹配随机注入比较，检查是否只是利用了位置规律。

“后段偏差大”与“后段适合加 steering”不是同一个结论。前者是观察，后者需要后段基线和教师恢复能力实验支持。若教师后段已无法恢复学生轨迹，学生侧干预未必能解决问题。

### 10.5 怎样解释可能出现的结果

| 观察结果 | 合理解释或下一步 |
| --- | --- |
| $T-R$ 稳定优于 $T-S$ 与 $R-S$ | 支持教师同家族差分有额外价值，但仍需长度、格式与正确性控制 |
| $R-S$ 最好 | 当前收益更可能来自家族／模式适配，主叙事应调整 |
| 动态优于全程，但不优于随机稀疏 | 说明减少干预可能重要，尚未证明门控信号有效 |
| overlap 上升，裸学生准确率不升 | 局部相容性不足以带来能力收益，或模型依赖辅助 |
| 只在训练初期有效 | 可能是初始化／早期模式适配作用，不必扩展成动态提取 |
| 同家族低 overlap 有效，跨家族无效 | 收敛到分布失配 OPD；不宣称解决跨家族迁移 |
| 同数据 warm-up 更好且更便宜 | steering 暂不能作为预热替代，检查是否还有互补收益 |
| 只在测试时保留 steering 才有效 | 属于受控推理收益，不能作为独立学生蒸馏成果 |

## 11 跨 tokenizer 的实际处理

### 11.1 必须区分两种对齐

第一种是**对已发生文本动作评分**：把学生已经生成的文本重新分词，按共同文本边界合并 span，比较双方对同一 span 的编码路径 log-likelihood。CompassOPD 使用此类办法得到跨 tokenizer 的更新信号。[2]

第二种是**比较尚未采样的完整候选分布**：需要教师与学生在同一个动作空间上的归一化分布，才能定义第 7 节的 top-k overlap、熵和全词表 KL。

第一种并不自动提供第二种。将“unbelievable”的一个学生 token 与多个教师 token 对齐，只能处理这段文本的评分；它没有直接给出所有学生候选 token 在教师词表下的完整概率分布。不能把 token ID 交集、各自分词下的原始熵，或单个 span 分数当成已解决这个问题。

### 11.2 主结论与跨词表扩展分表报告

优先在兼容 tokenizer 的配对上完成三乘三机制矩阵。如果跨家族配对恰好满足兼容条件，也可使用相同定义直接验证跨家族。

对于真正不同 tokenizer 的师生，使用以下两条清楚区分的扩展路径。

**路径 A 使用已经复现的完整分布对齐器。** 只有当对齐器能在共同前缀上输出共同动作支持的归一化概率分布、处理多对多映射并报告保留质量时，才继续使用 overlap 单指标门控。普通 OPD、本方法和相关基线必须共享同一个对齐器，单独报告其额外成本与误差。若没有这种实现，不假定现成存在。

**路径 B 使用共同下一字节分布作较粗的在线门控，并使用文本 span 评分作蒸馏。** 在可正确解码的共同文本前缀上，将每个候选 token 按其将输出的第一个字节聚合：

$$
P^B(b\mid c)=\sum_{a:\;\operatorname{firstByte}(a;c)=b}P(a\mid c).
$$

共同支持包括 256 个字节，以及单独定义的 EOS／其他控制输出类别；需要使用上下文相关的增量解码，正确处理空格、特殊 token 和不完整 UTF-8 字符。普通 token 必须有明确的非空字节输出，所有质量都映射到明确定义的类别。若当前学生前缀尚未形成可重编码文本，就沿用此前因果可得的门控，直到下一个合法边界再更新。

双方在这一共同字节空间上只使用 $\sum_b\min(P_S^B(b),P_T^B(b))$ 作为相交指标，并通过单一阈值控制学生后续预测；熵差不作为附加触发条件；蒸馏目标沿用同一套 CompassOPD 式文本 span 评分和 token 分配实现。所有比较方法共享相同 span 映射规则，不把路径评分解释为对所有字符串分词方式求和后的精确边缘概率。

路径 B 是一个可以实现的跨词表变体，但它的相交指标只看下一字节，区分度可能弱，**不等同于原始 top-k token overlap，也不等同于全词表反向 KL**。应先做门控区分度与预算检查，再决定是否扩大实验。相应结果单独成表，不能与主机制指标直接平均。

### 11.3 纯文本教师的边界

如果教师仅提供完整回答、不提供概率或可本地访问的 logits，方向提取仍可实施，但本文默认的教师分布门控和直接 OPD 不能原样运行。可改用 BSD 式同词表自教师桥接，[8] 但此时应明确改名为桥接变体，重新比较监督来源与额外信息。

这不是方向提取的限制，而是在线概率门控与 OPD 监督所需接口的限制。第一版不把纯文本教师也纳入主方法必须同时解决的范围。

## 12 训练成本和实现优先级

### 12.1 不能只按向量加法成本宣传轻量

离线成本包括三类回答生成、学生对三类回答的读取，以及层和强度校准。小参考只在离线提取时使用，主训练不需要每一步再运行小参考，这是与在线教师家族差分方法的一项潜在成本区别。

但主门控需要在采样下一 token 之前知道教师当前分布。普通 OPD 可能先快速生成完整 rollout，再批量让教师评分；动态门控则使教师与学生逐步交互，可能显著影响吞吐和批处理效率。学生本身还可能需要当前步探测和重算。

因此，本方法可以先定位为“改善蒸馏有效性”，不能在测量前声称比 SFT warm-up 或 CompassOPD 更省总算力。固定训练 token 预算和固定实际计算预算的结果都应报告。

### 12.2 实现顺序

1. 先跑无干预普通 OPD，确认教师确实提供能力优势、低 overlap 设置确实存在学习困难。
2. 完成三种方向提取、向量分解和固定前缀单步注入诊断。
3. 实现每个 token 注入，验证生成与训练重放的一致性。
4. 实现完整当前步探测的动态门控，先保证定义正确，再优化缓存和批处理。
5. 加入后段注入、随机稀疏及独立的熵差门控对照，完成三乘三矩阵。
6. 完成独立学生评测、warm-up 与 CompassOPD 对比，再扩展模型与跨 tokenizer 设置。

优化可尝试复用 hook 层之前的当前步计算，减少重复的下半段前向；必须先验证结果一致。用上一 token 的指标控制当前 token 也能减少部分同步要求，但它属于**滞后一拍门控**，应作为明确命名的效率变体，不能悄悄替代主方法。

### 12.3 预算分成三类

| 预算 | 要记录什么 | 为什么 |
| --- | --- | --- |
| 数据预算 | 教师文本条数、生成 token、方向数据、预热数据 | 判断收益是否来自更多教师信息 |
| 学习预算 | 学生更新次数、训练 token、训练阶段 | 判断是否只是多训练了 |
| 实际计算预算 | 教师／学生前向量、逐步交互开销、墙钟时间 | 判断是否具有工程价值 |

动态方法注入得少，不代表教师调用就少，因为它可能每一步都要先查询教师才能决定是否注入。这个区别必须在成本表中体现。

## 13 分阶段执行与停止标准

### 阶段一 验证方向是否存在可用信号

在一个预定低 overlap 配对上，用 256–512 道训练题提取三种方向。在独立前缀上比较正向、反向、随机方向，观察即时分布变化和少量续写表现。

该阶段只用于筛掉明显错误的 hook、尺度和无信号方向。不要仅凭即时 overlap 没有上升就断言训练干预完全无效；但如果合理层和强度下持续导致退化，也不应直接投入大训练。

**产出：** 向量范数／夹角表、层与强度校准结果、固定前缀诊断图。所有方向使用相同搜索预算。

### 阶段二 完成最小训练闭环

先用相同总预算试跑普通 OPD、三种方向的动态注入，以及主方向的全程和后段注入。确认裸学生存在可复现趋势，再补齐完整三乘三矩阵与随机门控。

**通过条件：** 至少出现对普通 OPD 的裸学生增量，且趋势不能由等范数随机方向完全解释。若只有受控推理提升，先处理辅助依赖问题，不继续把它包装为蒸馏收益。

### 阶段三 完成公平强基线与机制证据

加入同数据 warm-up + OPD、共同预热轨道的 CompassOPD、熵感知 OPD，以及格式／长度／正确性控制。对关键比较运行至少 3 个训练种子。

**通过条件：** 主方向和动态触发至少各有一项明确增量，或实验清楚说明只有其中一项必要。若方案二没有优势，就按结果改主方法，而不是只展示它胜出的子集。

### 阶段四 检验跨家族与适用边界

把选定配置迁移到额外学生或教师，并按第 11 节区分兼容和不兼容 tokenizer。跨家族为优先外部验证方向，但不是预设成功结论。

**收敛标准：** 若跨家族没有稳定增益，而同家族低 overlap 配对有效，收敛为“面向低相容师生的 OPD 表示干预”。仍需多配对复现，不能只凭单一失败恢复案例支撑普遍机制。

## 14 预期论文贡献与表述边界

如果实验支持，论文可主张三项贡献：

1. 在学生内部构造教师同家族差分方向，并系统比较 $T-R$、$T-S$、$R-S$，分析哪种差异有利于 OPD。
2. 将当前学生前缀上的师生分歧用于控制学生激活干预，证明其相对全程、固定后段及预算匹配随机注入的价值。
3. 用固定状态诊断、去干预评测和公平数据／计算预算，区分即时对齐、状态访问变化与学生独立能力学习，并给出有效边界。

如果只完成低 overlap 同家族结果，就按这一范围写贡献；如果跨家族、跨 tokenizer 也成立，再扩大表述。没有实验之前，不写“消除了家族偏移”“提取了纯能力”“steering 必然增加有效梯度”或“解决所有跨家族蒸馏”。

可以保留的关键结论形式是：**在给定师生配对与预算下，教师同家族差分是否比直接师生差更有用；同样数量的干预，是否放在分歧状态上更有效；这些收益是否能在撤去干预后保留。**

## 15 最终采用的第一版配置

| 项目 | 第一版选择 |
| --- | --- |
| 首要任务 | 可验证答案的数学推理 |
| 机制场景 | 兼容 tokenizer 的低 overlap 师生 |
| 优先外部验证 | 跨家族，按 tokenizer 条件分开处理 |
| 读取激活的模型 | 当前轨道训练开始前的冻结学生 |
| 主方向 | 学生读大教师回答减学生读教师同家族小参考回答 |
| 必做方向对照 | 大教师减自身；小参考减自身 |
| 提取时机 | 训练前一次，之后固定 |
| 方向粒度 | 单层全局均值方向 |
| 主触发方式 | 仅按 overlap 单阈值触发，低于阈值即注入 |
| 必做时机对照 | 每个 token 注入；预定义后段注入 |
| 核心监督 | 同一教师的 OPD，门控不裁剪监督位置 |
| 生成与更新 | 使用一致的受控策略定义 |
| 主评测 | 完全去掉 steering 的独立学生 |
| 优先强基线 | 同数据 warm-up + OPD；CompassOPD；已有 steering 思路的 OPD 适配 |
| 不作为主轴 | 动态重新提取、多方向路由、多层控制器 |

这版方案把研究集中在两件事上：**方向到底应该减谁，以及干预到底应该放在哪里。** 其余设计首先用于保证这两件事可以被正确检验。
