# 相对层深度与取整约定

用户要求跨模型用层深度百分比指定候选。比例集合见summary.json；从学生config.json读取实际decoder层数，按十进制四舍五入到第几个block后减1得到0-based索引。
当前28层模型保持原映射[10,13,16,20]；32层为[12,15,18,23]；40层为[15,19,23,29]。
steering_method.layer_depths接受0到1之间的比例（不含0）；解析后保留原Method/bank绝对层号格式。
同时提供layers时校验二者一致；重复映射拒绝，不能静默减少层数。
