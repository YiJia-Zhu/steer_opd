# Steering能否改善OPD适配：跨family主线与回退方案

更新：2026-11-11。**当前只讨论方案，实验和下载仍暂停。**
论文配对与数据见[证据表](02_paper_settings.md)，实现细节见[执行说明](03_execution_plan.md)。

## 1. 我们到底想解决什么

**先研究跨family的教师—学生OPD适配：能否用少量教师示范提取学生自己的激活
方向，帮助学生学会教师的监督，并在撤去steering后仍有收益？**

这里的难点是：教师自己做题很强，不代表它在学生已经生成的推理前缀上，给出的
逐步指导就容易被学生学会。即使分词已经对齐、先做过SFT，后面的OPD仍可能收益有限。
我们想试的是，轻量的学生内部干预能否改善这一步。

“同一个教师教不同学生”只是以后可做的对照，不是研究主问题，也不要求所有实验
共用一个教师。每次训练仍冻结教师参数，但可以使用论文中不同的师生配对。

**不预设steering一定有效。** 如果跨family没有可靠收益，就回到Rethinking的
共享词表设置，研究更窄的问题：方向能否改善原有的OPD学习困难，或者减少SFT
冷启动的成本。若这个设置也没有收益，就记录负结果，不硬说方法成功。

## 2. 方案1：先用最简单的教师—学生方向

以一个确定的跨family配对开始，不先铺开多个学生、多个方向或大量超参。

1. 从独立校准题中先取128题，让教师给出推理回答，也让初始学生自己回答。
2. 冻结学生，让它用自己的分词器分别读取两类回答，提取同一层的内容激活。
3. 每题先平均，再跨题取平均，得到方向：
   `v = 学生读取教师回答的激活 - 学生读取自身回答的激活`。
4. 学生照常生成训练轨迹。只在早期计算训练loss时加入这个方向，更新学生参数。
5. 撤去方向，继续普通OPD，最后评测不带方向的学生。

两项激活都来自同一个学生，不能直接拿教师hidden state减学生hidden state。
教师文本那一项只需学生读一遍；参考项还要读自己的回答，所以通常是每题两次
学生prefill。它是否比SFT便宜，要把教师生成、学生读取和后续训练一起计费。

先只用一个中间层、一个全局方向。真实、随机和负方向用相同层、强度与时长。
具体池化、长度控制、mask和梯度重算放在执行说明的技术附录，不在这里当作已解决的效果。

## 3. 方案2：借鉴Compass，减去教师家族里也有的偏移

这是方案1之外的候选，先做小比较，不因为名字更复杂就默认更有效。

Compass的想法是：强教师相对一个同家族弱模型多出来的偏好，可能比“直接模仿
强教师的全部分布”更有用。我们把这个想法用于方向构造：

- 同一批题，再让教师同家族的弱参考模型回答。
- 三类文本都由同一个冻结学生读取。
- 方案2方向取`学生读取强教师回答的激活 - 学生读取弱参考回答的激活`。
- 另保留“弱参考−学生”方向作对照，看看真正有用的是哪部分。

在相同题目、池化和权重下，总差可以写成“教师−弱参考”加“弱参考−学生”。
但前一项不自动等于纯能力，后一项也不自动等于纯风格；回答内容、长度和正确性
都可能影响它们，仍需实验区分。

方案2可先接普通OPD，也可接Compass。比较时分开两个因素：是否换了方向，是否
换了OPD目标。不能只用“方案2+Compass”赢“方案1+普通OPD”，就断言方向更好。
方案2多出的参考模型生成、读取和评分成本也要算。

## 4. 师生分词不一样怎么办

先按Compass的思路，把同一段可见文本按共同边界对应起来。例如学生把
`unbelievable`看成1个token、教师拆成3个，就在完整文本片段上对应，不能比较
相同整数token ID。无法可靠对应的位置跳过，并报告比例。

Compass多token片段用平均token log-prob作评分。这个平均值不等于整个单词的
概率，也不能直接叫精确的跨词表KL。分词对齐只是把监督接上，不保证学生就能学好。

还有一个实现问题：轨迹由普通学生生成，加方向后的学生分布会变化，不能把普通
样本直接塞进假定“由加方向模型采样”的公式。方法比较先采用明确定义的候选
分布loss，原版Compass采样基线另列；它们的区别和公式见执行说明技术附录。
如果只在这个适配目标下有效，结论也只能覆盖这个目标，不能扩大成所有OPD。

## 5. 怎么判断steering真的有用

主要看：**撤去方向后，普通学生是否学得更好，或者用更少总成本达到相近成绩。**

需要比较的对手：

| 对照 | 用来排除什么解释 |
|---|---|
| 普通OPD | 原来的训练本来就有效，方向没有额外作用 |
| 同范数随机方向、负方向 | 只是一般扰动，或者方向符号没有我们想的含义 |
| 同一批教师回答做full SFT→OPD | 普通SFT已经能完成适配 |
| 同一批回答做LoRA→OPD | 更轻量的Simple式warm-up已经足够 |
| SV-SFT→OPD | 参考论文的训练方法已经能取得同样收益 |
| Compass及其方向组合 | 改监督信号是否已足够，学生方向是否还有附加价值 |

每组从相同学生起点出发，给SFT/LoRA合理调参机会。按照Compass共同SFT起点
比较时，所有组用同一个SFT checkpoint；不能让某组多做一次隐含训练。

Overlap只作诊断。它升高可能只是开头空格或措辞变了；如果关掉方向没有学习收益，
就不能说解决了适配。反过来，任务收益好但overlap没升，也应如实记录，不能只
围着一个指标讲故事。

## 6. 根据结果走哪条路线

| 看到的结果 | 下一步 | 可以说什么 |
|---|---|---|
| 跨family中，关掉方向后仍稳定优于普通OPD和有力对照 | 再确认种子、成本和另一组师生 | 在已测试的跨family配对中改善了OPD适配 |
| 只有开方向时overlap提高，关掉后没有收益 | 先检查格式、长度、实现和训练预算，不直接扩实验 | 只改变了即时输出，尚无学习改善证据 |
| 排除明显实现问题，在约定预算内跨family仍没有额外收益 | 回到Rethinking共享词表设置重新实验 | 跨family方案暂未得到支持，缩小研究范围 |
| 共享词表设置有效，跨family仍无效 | 围绕共享词表下的OPD可学性、冷启动和成本写结果 | 效果只在这个范围成立，不能继续说解决跨family |
| 共享词表下也没有可靠收益 | 停止扩张方法，整理负结果和适用边界 | 当前方向构造/注入方式没有显示优势 |

回退要做新的、范围更窄的实验，不能只换论文措辞。跨family负结果保留，路线
选择用dev，不能看过MATH-500后再挑故事。回退后若只是复现已有“SFT有效”，也
不能包装成新的方法贡献。

## 7. 每条路线选什么模型

所有配对优先对应已有论文，不按“容易下载”临时换模型。

| 用途 | 教师→学生 | 说明 |

| 回退F1 | Qwen3-4B non-thinking→Qwen3-1.7B-Base | Rethinking的SFT修复设置，直接研究模式适配与SFT比较；Base不能用Instruct替换 |

| 有主结果后再加C3 | Qwen3.5-4B→Qwen3-4B | Compass已有的4B级规模控制，仍共享广义Qwen谱系，不能替代C1独立家族证据 |

目前Granite、F1的1.7B-Base、C3的4B教师等仍有缺口。先讨论必要性，不下载全部
模型。严格独立家族的3B→3B新配对不是当前必须项，不再扩张为新的主问题。

## 8. 数据和选择怎样保持简单

- 校准题先128道，T生成教师回答，S生成自身回答；方案2才加弱参考回答。
- 保留完整、非退化回答，报告正确率和截断；正确示范子集作为单独对照。各方法
  使用相同题目/教师文本，不让方案2独享额外筛题或信息优势。
- 学习用独立训练题；dev-select选层/强度，dev-confirm只确认冻结后的选择。
- MATH-500始终是冻结测试，不用来选模型、方向或决定是否回退。
- 若以后才做“同教师、多个学生”，再统一校准题和教师文本；这不是首轮硬要求。

先做短程学习筛选，确认梯度和更新正常，再在关方向后评dev。有希望的候选延长
到50/100步确认，只有实际收益值得继续时才进入长训练和多种子。10步没有显著
差异不足以证明无效，但也不无限加超参寻找一个好结果。预算和判断条件提前记录。

## 9. 当前最小待办

1. 确认跨family试验的模型、分词接口、已有资产与预算；当前不启动。
2. 在C1上保留普通OPD、方向、随机和SFT/LoRA等必要比较，先看真实学习。
3. 有证据后再加方案2、Compass组合、等规模控制或其他学生，不先铺满矩阵。
4. 跨family在合理检查后无收益，就启动F1/R1回退设计，简化为共享词表下的适配。
5. 两条路线都没有收益时，接受负结果，不继续用“思维相容”替代效果证据。

目前没有正式跨family训练结果能确认steering有效或无效。效果可能有限是工作假设，
需要用上述比较来判断。进度与约束统一维护在[AGENTS](../AGENTS.md)。
